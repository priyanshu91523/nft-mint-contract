# NFT Mint Smart Contract

A simple ERC721 NFT minting smart contract built using Solidity and OpenZeppelin.

## Features

- Mint function
- NFT metadata support
- IPFS integration
- Whitelist minting

## Skills Demonstrated

- ERC721 implementation
- Smart contract mint logic
- Solidity events
- OpenZeppelin contracts

## Tech Stack

- Solidity
- Hardhat
- OpenZeppelin
- IPFS

## How to Deploy

1. Install dependencies
npm install

2. Compile contract
npx hardhat compile

3. Deploy
npx hardhat run scripts/deploy.js --network sepolia
